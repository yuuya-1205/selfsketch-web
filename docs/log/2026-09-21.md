  以下のエラーが起きた。
  npm error Missing script: "type"
  npm error

  npm error npm run

package.jsonにtypeを追加していないために起きたエラーかな。
これを後ほど確かめる。

解決方法
package.jsonのscriptにtypecheckを追加して
"typecheck": "tsc --noEmit"を追加したことでエラーは解除された。

- 2つ目
  Error: src/app/layout.tsx(20,50): error TS2304: Cannot find name 'LayoutProps'.
  Error: Process completed with exit code 2.

  LayoutPropsがglobalでimportが不要なパッケージって話。
  これが.nextがないからかな。

  CIは.nextがない状態から始まるからねー
  それを回避するためにbuildしたりしないといけないかな。

## 整理

package.jsonのscriptsにあるものをnpm run 〇〇にdevなどを入れる実行されることであっているか？
"tsc --noEmit"これはどこにあるのか？

script名にtypecheckを採用した理由：
package.jsonには"type":"module"という別の設定項目があり、これと分けたいと考えたため。
