# 学習ログ

`docs/learning-plan.md` の「学んだことは docs/ に残す」の置き場。

## 書き方

- **1 週間 1 ファイル。** ファイル名はその週の月曜日の日付（例: `2026-09-14.md`）
- PR を出すたびに追記する。あとでまとめて書かない
- 書く欄は 6 つ。埋まらない欄は空のままでよい

| 欄 | 書くこと |
| --- | --- |
| やったこと | 出した PR と一言 |
| 決めたことと理由 | 何を選び、なぜか。**採らなかった選択肢**も書く |
| 学んだこと | 知らなかったこと、思っていたのと違ったこと |
| 段階の宣言 | 技術ごとに「自分で書く / AI が下書き / AI に任せる」を変えたら一行 |
| 時間 | その週に使った時間。フェーズの実績に転記する |
| 宿題 | あとで自分で理解し直したいこと。チェックボックスで書き、済んだら消さずにチェックを入れる |

## なぜこの形か

- 決めた理由と採らなかった選択肢を残すのが目的なので、日記ではなく判断の記録にする
- 1 日 1 ファイルだと空の日が増え、フェーズ 1 ファイルだと大きすぎて追記しなくなる。週が中間
- ADR（意思決定記録）を別ディレクトリに分ける方式は、今の規模では二重管理になるので採らない。
  必要になったら「決めたことと理由」の欄から切り出す
